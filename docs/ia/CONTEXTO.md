# Contexto — Pro Security Systems

## Resumen
Sitio web de Pro Security Systems: cercos eléctricos, portones automáticos, cámaras de seguridad, control de acceso y citofonía.
Sitio en vivo: https://pro-security-systems.vercel.app/

## Objetivo del sitio
Presentar los servicios de seguridad y captar solicitudes de cotización.

## Público
Hogares, condominios y empresas que necesitan seguridad perimetral y control de acceso.

## Secciones
- Inicio
- Servicios: cercos eléctricos, portones eléctricos, cámaras, control de acceso y citofonía
- Nosotros
- Contacto y llamado a cotizar

## Contenido y datos
- Los textos, precios, teléfonos y certificaciones los entrega el cliente. La IA no inventa información del negocio: si falta un dato, se deja marcado como "por confirmar".
- Las especificaciones técnicas y garantías las confirma el cliente antes de publicarlas.

## Restricciones
- Este repositorio contiene solo el frontend (sin backend propio).
- No se suben secretos ni datos personales. Las variables de entorno van en .env (no versionado) y solo se usan variables públicas VITE_*.
- El dominio y el despliegue los gestiona una persona, no la IA.
