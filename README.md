# Pro Security Systems

Sitio web de **Pro Security Systems**, empresa de seguridad para hogares, condominios y empresas: cercos eléctricos, portones eléctricos, cámaras de seguridad, control de acceso y citofonía.

**Sitio en vivo:** https://pro-security-systems.vercel.app/

## Secciones

- Inicio, Servicios (cercos eléctricos, portones eléctricos, cámaras / control de acceso / citofonía), Nosotros y Contacto
- Llamado a la acción para cotizar

## Stack

- React + TypeScript
- React Router
- Vite
- Tailwind CSS
- Despliegue en Vercel

## Cómo ejecutarlo

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # build de producción
```
